Dynamic Form

Use a form shell with an iterate operation for field/column definitions and bind metadata into generated controls.

columns[] → iterate → control template

Dynamic Table

Combine a header iteration with a nested row × column iteration to produce a complete table specification.

columns[] → thead
rows[] × columns[] → tbody
