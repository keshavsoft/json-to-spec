What is json-to-spec?

The repository describes itself as a compiler for declarative UI: it reads two JSON inputs and emits a final, concrete UI specification.

Structure = blueprint

The shape, layout, rules and instructions for the UI.

Data = truth

Fields, values, arrays, rows and metadata supplied to the blueprint.

Compiler contract

structure + data
      ↓
   compile
      ↓
 final JSON spec

Scope

The repository is a compiler, not a DOM renderer, framework or business-logic engine. Its output is a clean serializable specification tree.
