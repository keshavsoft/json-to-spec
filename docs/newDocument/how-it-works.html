04 · HOW IT WORKS

From two JSON files to one concrete spec.

1 · Define structure

{
  "tagName": "div",
  "children": [
    { "tagName": "h3", "textContent": "${title}" },
    {
      "operation": "iterate",
      "source": "users",
      "template": {
        "tagName": "div",
        "textContent": "${$number}. ${name} (${role})"
      }
    }
  ]
}

2 · Provide data

{
  "title": "Engineering Team",
  "users": [
    { "name": "Karthik", "role": "Architect" },
    { "name": "Praveen", "role": "Engineer" }
  ]
}

3 · Compile

const spec = compile({
  inStructure: structure,
  inData: data
});

4 · Result

{
  "tagName": "div",
  "children": [
    { "tagName": "h3", "textContent": "Engineering Team" },
    { "tagName": "div", "textContent": "1. Karthik (Architect)" },
    { "tagName": "div", "textContent": "2. Praveen (Engineer)" }
  ]
}
The compiler resolves values, replaces tokens and expands the iteration into concrete child nodes.
