03 · ARCHITECTURE

Compiler pipeline.

The repository documents a recursive tree traversal from normalized inputs to final specification JSON.

compile(structure, data) ↓ normalization ↓ recursive traversal ├─ array node → compile children → flatten └─ object node ├─ operation: iterate │ ├─ resolve collection │ ├─ filter invisible items │ ├─ bind loop context │ └─ compile template └─ standard element ├─ interpolate text ├─ interpolate attributes └─ preserve element structure ↓ final specification JSON

Core stages

Traversal

Walk arbitrary-depth arrays and objects recursively.

Operation detection

Recognize operation nodes such as iterate.

Interpolation

Resolve values and replace tokens in strings and element fields.
